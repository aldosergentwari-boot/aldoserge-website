# SERGE — Digital Identity

A personal portfolio for **Aldo Serge Ntwari**, designed around a dark, minimal visual identity with electric-blue accents.

## Overview

The website introduces Serge, highlights selected learning projects, shares areas of technical interest, and provides direct contact and social links.

## Built with

- HTML5
- CSS3 (responsive layouts, custom visual system, reduced-motion support)
- Vanilla JavaScript (mobile navigation, scroll progress, reveal effects, typing animation)

## Featured work

- **Phishing URL Detection System** — an offline-first machine-learning and threat-intelligence project for identifying suspicious URLs.
- **Serge Academy** — an educational web platform concept with learner accounts and a personal dashboard.
- **Ongoing experiments** — a space for new software and technology explorations.

## Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Assets

The portfolio uses the existing `Serge.jpg` portrait and `Serge1.ico` favicon. Keep both files in the project root.
